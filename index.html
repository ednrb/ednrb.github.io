Dumbify

Jun 2026–now

Chrome & Firefox extension · with Gabriel Tan · 52 active users at peak

YouTube, without the noise: feeds become plain text lists, and autoplay, end screens, and "Up next" are gone. YouTube's own player stays.

  • Reads the same data and InnerTube API that YouTube's own frontend uses, so subscribing, liking, and commenting work with your signed-in session.
  • TypeScript and plain DOM: no UI framework, no runtime dependencies. End-to-end tests run the built extension in headless Chromium.
  • Free, no ads, no server, no account. Open source under GPL-3.0.
